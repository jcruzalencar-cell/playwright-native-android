# Playwright Native Android - Termux Repository

Repositório APT oficial para o adaptador do **Playwright** voltado ao uso direto com o navegador nativo do Android (`com.android.chrome`) via daemon **ADB** local, sem a necessidade de baixar pacotes pesados de Chromium para desktop.

---

## 📦 Pacotes Disponíveis

* **`playwright-native-android`**: Adaptador leve em Node.js que interage com o `playwright-core` e o ADB do sistema.
